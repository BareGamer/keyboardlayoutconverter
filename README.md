# Keyboard Layout Converter

A lightweight utility that instantly converts text typed in the wrong keyboard layout. Press a hotkey combination to switch selected text between Latin and Cyrillic (and additional layouts) without retyping.

## ✨ Features
- 🔄 Instant conversion between Latin and Cyrillic layouts
- ⌨️ Hotkey-triggered text transformation
- 🌐 Support for multiple keyboard layouts
- 🖥️ Console and GUI interfaces
- ⚡ Fast and lightweight core engine
